# 🚀 Jogo Atari — Asteroids em Python

Um jogo arcade no estilo Atari, desenvolvido com **Python** e **Pygame**, inspirado no clássico Asteroids.

## 🎮 Como Jogar

- **← →** — Mover a nave
- **Espaço** — Atirar
- Destrua os asteroides antes que eles te atinjam!
- Se um asteroide passar da tela ou colidir com sua nave, é **Game Over**.

## 📁 Estrutura do Projeto

```
jogo-atari/
├── game.py       # Loop principal e lógica do jogo
├── sprites.py    # Classes dos sprites (Jogador, Tiro, Asteroide)
└── settings.py   # Configurações globais (velocidade, cores, tamanhos)
```

## ⚙️ Requisitos

- Python 3.8+
- Pygame

## 🛠️ Instalação

```bash
pip install pygame
python jogo-atari/game.py
```

## 🧠 Tecnologias

- Python 3
- Pygame (sprites, colisões, eventos, renderização)
